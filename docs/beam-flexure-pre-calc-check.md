## 4. 页面方案与第一版适用范围

按用户最新要求，工具名称为：**梁截面验算**，包含“正截面受弯承载力计算”和“斜截面受剪承载力计算”两个独立入口。先实现受弯入口，注明其范围为矩形截面正截面受弯；受剪入口在其独立开发并验收后提供，未实现时不展示可计算按钮。不增加双筋、T形截面或其他构件模块。

建议第一版只做：**已知配筋的非预应力单筋矩形截面梁正截面受弯承载力复核，不包含抗震专项验算。** 用户输入截面、实配受拉钢筋和设计弯矩，由程序验算；不反算配筋方案。

工程师提供作用于当前截面的设计弯矩及其组合说明。本模块不从荷载求内力，不自动进行配筋设计，不利用受压钢筋贡献，不验算受剪、裂缝、挠度、锚固或完整构造。采用普通强度范围内的混凝土和热轧带肋受力钢筋；具体可选等级待材料条文和模型范围确认后确定。若工程属于抗震设计情形，本版不能给出该情形的合格结论，须另行核对抗震规范并更新本报告。

页面布局：

1. 顶部显示“梁截面验算”，当前模块标题为“正截面受弯承载力计算”，注明“矩形截面”，并显示已确认规范版本、适用范围。受剪模块完成后增加独立入口“斜截面受剪承载力计算”。
2. 桌面左侧放参数输入和“开始计算”，右侧放 SVG 截面示意图，标注 b、h、受压边、受拉钢筋、a_s、h_0；手机按阅读顺序排列。
3. 计算后首先显示 M_d、适用模型下的 M_R、承载力判断及总体状态。
4. 紧接着显示输入/范围检查、材料要求、受压区高度、最小配筋等逐项判断。
5. 详细过程可折叠：名称、公式、参数含义与单位、代入、未舍入结果的格式化显示、条件比较、结论和条文链接。
6. 每个需要依据的步骤旁都有规范名称、条/表号和“查看规范原文”。网页内打开 PDF 并定位页码；显示 PDF 文件页序与规范印刷页码，避免混淆。

状态必须区分“满足本模块已检查项目”“不满足”“超出模型范围”“依据待确认”。不能把局部受弯复核结论写成整根梁或整个工程合格。输入变更后，旧结果标记为需重新计算。

| 规范判断 | 材料适用性；模型范围；x 与 x_b；实配与最小配筋；设计需求与承载力比较；每项实际值、限值和判断 |
| 最终结论 | 满足本模块检查项目 / 不满足 / 超出当前模型适用范围 / 依据待确认 |

## 7. 完整工程计算流程

以下是待规范与设计表达式确认后采用的顺序，不是已批准的计算算法。

1. 确认构件、截面、受拉边、工况和本模块适用范围；确认弯矩为设计值及重要性因素的处理位置。
2. 检查全部必填项、有限数值、正值、a_s 与 h 的关系、材料枚举和模型限制。不合法则结束，不产生计算结论。
3. 按确认的材料表取 f_c、f_t、f_y，逐项显示等级、设计值、单位和来源；检查通用规范对材料等级的要求。
4. 根据 b、h、a_s、A_s 建立截面；求 h_0=h-a_s。
5. 按本模块确认的条件取得 α_1、ξ_b；说明系数适用范围。
6. 根据已确认的内力平衡关系确定受压区高度 x，列出受拉力、受压力和数值代入。
7. 求 x_b=ξ_b h_0，比较 x≤x_b。若假定不成立，停止该模型的正式承载力输出，报告原因。
8. 求实配配筋率，按适用规范和表注确定 ρ_min，求 A_s,min；比较实际配筋与限值。
9. 在模型适用时求内力臂 z，再求截面承载力，先以 N·mm 计算，再转换为 kN·m。
10. 按确认后的承载能力极限状态表达式比较需求与承载力；不直接假定所有情形均为 M_d≤M_R。
11. 汇总各项判断及有限范围内的结论，保留输入、材料值、中间量和全部依据，使工程师能逐步按计算器复核。

程序内部采用 N、mm、mm²、N/mm²、N·mm；仅在输入/输出边界转换 kN·m。计算不提前舍入；界面显示精度不得改变真实比较。阈值相等及阈值两侧要有独立测试，不用宽松容差把不满足变成满足。

测试计划：正常算例、x=x_b 及两侧、最小配筋限值及两侧、承载力等于需求及两侧、低配筋/超出范围/承载力不足、非法输入、单位转换。正式正常算例及预期中间/最终值由人工计算确认后冻结，不以程序输出反过来作为唯一预期值。
