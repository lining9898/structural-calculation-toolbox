## 4. 页面与模型方案

工具名称“梁截面验算”，当前模块“正截面受弯承载力计算”；受剪是下一独立模块。

第一版建议限定为：普通静力、非疲劳、非预应力、单一牌号受拉钢筋、单筋矩形截面、非深受弯构件、不含抗震专项，不计受压钢筋贡献。混凝土仅C25—C50，钢筋仅HRB400、HRB500。

不自动处理第6.2.13条涉及的按构造或正常使用要求增加配筋后、按受弯所需配筋量进行特定计算的情形；若按实配面积得到x>ξ_bh₀，本版本报告“超出当前简化模型范围”，不能据此直接断言整个截面违法或已完成一般超筋截面分析。第6.2.14条关于计入普通受压钢筋的附加条件不加入本单筋模型。

页面包含输入、SVG示意图、计算按钮、承载力主要结果、逐项验算、可折叠完整过程、逐步条文和PDF原文查看。结论限定于已检查项目，不能等同整根梁或工程全面合格；不检查裂缝、挠度、锚固、耐久性、完整构造或受剪。

## 5. 全部拟采用输入

| 参数 | 符号 | 单位/方式 | 必填 | 来源与口径 |

| 实配受拉钢筋总面积 | A_s | mm²/数字 | 是 | 图纸汇总；单一牌号；>0 |
| 混凝土等级 | — | 下拉C25—C50 | 是 | 图纸；自动读取f_c、f_t |
| 受拉钢筋牌号 | — | 下拉HRB400/HRB500 | 是 | 图纸；自动读取f_y、E_s |

| 弯矩口径确认 | — | 明确勾选 | 是 | 工程师确认M_d不是未处理重要性因素的原始组合效应S |
| 受拉边 | — | 上/下选择 | 是 | 钢筋面积和a_s须对应此边 |
| 弯矩来源、组合和因素处理说明 | — | 文本 | 是 | 外部分析结果，程序不替工程师证明作用组合正确 |
| 梁类别 | — | 普通梁/框架梁 | 是 | 框架梁按GB55008第4.4.4条额外检查b≥200mm；普通梁不伪造同一条最小宽度要求 |

## 6. 输出结果

- 主要结果：M_d、截面抗力M_R（kN·m）、M_d≤M_R判断。
- 中间结果：材料设计值、α₁、β₁、ε_cu、ξ_b、h₀、受拉力T、受压力C、x、x_b、力臂z、ρ、ρ_min、A_s,min、N·mm与kN·m转换。
- 验算：模型范围、材料组合、框架梁宽度（适用时）、受压区限制、最小配筋、承载力比较。
- 最终状态：满足本模块检查项目/不满足/超出模型范围/依据待确认。
- 输入、材料、公式、代入、数值、限值、比较和原文入口逐步跟随显示。非法输入不计算，模型假定不成立时不输出有效承载力；低于最小配筋时不能给出合格结论。

## 7. 完整工程计算流程

确认模型、设计弯矩及受拉边→检查输入和适用范围→读取材料设计值并检查组合→检查框架梁宽度（适用时）→求h₀→取α₁、β₁、ε_cu→求ξ_b及x_b→按平衡求T、C、x→确认x≤x_b，失败则停止该模型正式承载力输出→求ρ、ρ_min、A_s,min并比较→在模型适用时求z、截面弯矩抗力与M_R→转换单位→比较M_d≤M_R→汇总有限范围内结论。材料、作用或范围未知时停止，不以经验值补齐。

## 8. 完整公式清单

本表“已读原文”不是工程师批准标记；单筋公式为将原式中的预应力筋、受压筋项置零后的代数简化，不伪装为原标准另列的公式编号。

| 名称 | 拟实现表达式 | 符号/单位 | 适用条件与规范依据 |
|---|---|---|---|
| 有效高度 | h₀=h−a_s | 长度均mm | 几何关系；h₀定义见第6.2.7条，a_s定义见第6.2.14条 |
| 应力图系数 | α₁=1.0，β₁=0.80 | 无量纲 | 本版C25—C50；第6.2.6条；不扩展到>C50 |
| 混凝土极限压应变 | ε_cu=min(0.0033,0.0033−(f_cu,k−50)×10⁻⁵)，本范围为0.0033 | ε无量纲；f_cu,k以N/mm²数值代入 | 非均匀受压；式6.2.1-5及其取值限制；f_cu,k不是f_c |
| 界限相对受压区 | ξ_b=β₁/(1+f_y/(E_sε_cu)) | 无量纲；强度及E_s均N/mm² | 有屈服点普通钢筋，单一牌号；式6.2.7-1 |
| 界限受压区高度 | x_b=ξ_bh₀ | mm | 第6.2.7条的定义 |
| 受拉合力 | T=f_yA_s | N/mm²×mm²=N | 钢筋达到对应抗拉设计值的模型；第6.2.10条简化 |
| 等效受压合力 | C=α₁f_cbx | N/mm²×mm×mm=N | 等效矩形压应力图，式6.2.10-2简化 |
| 内力平衡与受压区 | C=T；x=f_yA_s/(α₁f_cb) | x为mm | 无预应力筋、不计受压筋；式6.2.10-2简化 |
| 受压区限制 | x≤ξ_bh₀ | mm与mm比较 | 式6.2.10-3；不处理第6.2.13条特定例外 |
| 拉压内力臂 | z=h₀−x/2 | mm | 等效矩形应力图，式6.2.10-1简化 |
| 截面弯矩抗力 | M_u=α₁f_cbx(h₀−x/2)=f_yA_s(h₀−x/2) | N·mm | 单筋矩形、上述假定成立；式6.2.10-1简化；M_u为本程序中间变量 |
| 抗力设计值 | M_R=M_u/γ_Rd，本模型γ_Rd=1.0 | N·mm | GB55001第3.1.13条；γ_Rd取值另对照静力规定并待确认 |
| 最小配筋率 | ρ_min=max(0.002,0.45f_t/f_y) | 无量纲，显示乘100为% | GB55008第4.4.6条/表4.4.6；本模块梁不采用特定板类0.15%例外 |
| 实际配筋率 | ρ=A_s/(bh) | 无量纲 | 矩形受弯截面，无受压翼缘扣除；GB55008表4.4.6注2 |
| 最小钢筋面积 | A_s,min=ρ_minbh | mm² | 由确认的配筋率口径代数反算 |
| 最小配筋检查 | ρ≥ρ_min，等价A_s≥A_s,min | 两侧单位相同 | GB55008第4.4.6条 |
| 材料组合检查 | HRB500时混凝土不低于C30 | 等级条件 | 2024修订第4.1.2条；需与GB55008材料规定衔接 |
| 框架梁宽度检查 | b≥200mm | mm | 仅框架梁；GB55008第4.4.4条第1款 |
| 承载力比较 | M_d≤M_R，输入M_d=γ₀S的弯矩形式 | 两侧统一N·mm | GB55001第3.1.13条；2015正文第3.3.2条注与第6.2.10条；禁止再重复乘γ₀ |
| 单位转换 | M[N·mm]=10⁶M[kN·m] | N·mm↔kN·m | 单位定义；不虚构规范条号 |
