# 结构计算工具箱

面向结构工程师的 Web 结构构件计算工具箱。

## 当前状态

全新项目；不继承历史仓库代码。正在开发梁截面验算，先正截面受弯，验收后再斜截面受剪。

第二版 PRE-CALC CHECK 已获确认。受弯模块现已实现确定性承载力计算、输入检查、受压区限值、最小配筋、框架梁宽度检查、完整代入过程及逐步规范原文入口。当前等待工程师人工验收，尚未合入 dev 或稳定分支。

范围：普通静力、非疲劳、非预应力、单筋矩形截面，C25—C50，HRB400/HRB500；不支持深受弯构件、抗震专项或受压钢筋贡献。输入弯矩必须已包含结构重要性因素。超出模型或前置条件不满足时，不输出有效设计承载力。

## 本地运行

需要 Node.js 22.12 或更高兼容版本；当前在 Node.js 24 上验证。

```sh
npm ci
npm run dev
```

```sh
npm run build
npm test
```

部署产物为 `dist/`，不需要数据库或后端。依赖版本由 `package-lock.json` 锁定。核心公式独立保存在受弯模块内；公共文件只保存材料表与单位工具。

## 验证与规范原文

- 39 项受弯模块测试与 7 项公共单位测试全部通过，包含独立高精度参考值、临界值两侧、不满足条件和非法输入。
- 浏览器已检查桌面和手机布局、结果失效、模型超限、输入错误及真实本地 PDF 页码入口。
- 数值参考值仍需工程师手算复核；测试通过不等于工程验收。
- 原始 PDF 只供本地查阅，`public/standards/*.pdf` 已忽略，不推送公开仓库。生产构建可能含本地 PDF，未经原文公开授权不得发布该目录。
- 本地原文文件名：`public/standards/gb50010-2015.pdf`、`public/standards/gb50010-2024-amendment.pdf`。2015 正文与 2024 局部修订配合使用；通用规范提供官方原文链接，外部内嵌可能受网站限制。

方案见 [PRE-CALC CHECK 第二版](docs/beam-flexure-pre-calc-check-v2.md)，实现与验收报告见 [受弯模块报告](docs/beam-flexure-development-report.md)。

## 分支约定

- `dev`：项目初始化及开发集成。
- `module/beam-flexure`：正截面受弯模块开发。
- `module/beam-shear`：受弯验收后再建立。
- `master`：人工验收后的稳定版本；未获验收不得合入。

空仓库的首次提交仅为此项目说明，默认 `main` 暂作初始化基点；应用代码只在开发分支提交。
