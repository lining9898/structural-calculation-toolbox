# 结构计算工具箱

面向结构工程师的 Web 结构构件计算工具箱。

## 当前状态

全新项目；不继承历史仓库代码。正在开发梁截面验算，先正截面受弯，验收后再斜截面受剪。

已建立参数输入、中文输入检查、截面示意图、几何有效高度代入、折叠过程、逐步规范依据和官方 PDF 原文入口。计算由确定性程序执行，所有关键公式与规范依据须确认后实现。当前关键规范仍待确认，尚无正式承载力计算功能；输入检查通过不代表规范验算通过。

## 本地运行

需要 Node.js 22.12 或更高兼容版本；当前在 Node.js 24 上验证。

```sh
npm ci
npm run dev
```

```sh
npm run build
npm test
```

部署产物为 `dist/`，不需要数据库或后端。依赖版本由 `package-lock.json` 锁定。不得绕过规范确认直接添加承载力公式或材料设计值。

## 当前检查范围

- 独立受弯输入检查、几何边界和关键依据缺失时的阻止输出。
- 公共单位转换。
- 尚未开展结构承载力标准算例、规范限值算例或人工验收；这些需要先确认规范、公式和手算预期值。
- 原文入口引用住建部官方 GB 55008 PDF，未把规范 PDF 分发到公开仓库。内嵌或页码定位失败时可回到官方发布页；页面不保证外站永远可用。

详细核对见 [PRE-CALC CHECK](docs/beam-flexure-pre-calc-check.md)。

## 分支约定

- `dev`：项目初始化及开发集成。
- `module/beam-flexure`：正截面受弯模块开发。
- `module/beam-shear`：受弯验收后再建立。
- `master`：人工验收后的稳定版本；未获验收不得合入。

空仓库的首次提交仅为此项目说明，默认 `main` 暂作初始化基点；应用代码只在开发分支提交。
